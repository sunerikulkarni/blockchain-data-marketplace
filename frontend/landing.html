About DataChain

What is DataChain?

DataChain is a data marketplace where dataset owners can publish their data and users or companies can discover, request access to, and purchase datasets. Ownership and transactions are recorded through the blockchain for transparency and verifiability.

Centralized Marketplace Interface

Browse datasets through a unified marketplace. Owners publish datasets, and users or companies can discover and request access through the same interface.

Permission-Controlled Access

Dataset owners retain control. Access requests are reviewed and approved or rejected by the owner before data becomes accessible.

Blockchain Ownership Records

Dataset ownership and important marketplace actions are recorded through the Ethereum Sepolia blockchain, providing transparent and tamper-resistant records.

Encrypted Storage on IPFS

Protected dataset files are encrypted with AES-256-GCM and stored on IPFS. Only authorized users can retrieve and decrypt the actual data.

Features

Key Features

DataChain brings together blockchain verification, encrypted storage, and permission-controlled access into a single marketplace platform.

Secure Data Marketplace

Discover and manage datasets through a centralized marketplace interface. Browse by category, view ownership details, and initiate access requests.

Blockchain-based Ownership

Dataset ownership and important marketplace actions are recorded through the blockchain, providing a transparent and verifiable ownership trail.

Permission-controlled Access

Dataset owners can approve or reject access requests. Access is explicitly granted before any data is made available to a requester.

Encrypted Data

Protected data is encrypted using AES-256-GCM before storage. Only authorized users with valid session tokens can decrypt and access the actual content.

Data Integrity

SHA-256 hashing is used to verify that retrieved data has not been modified. The hash stored on-chain is compared against the retrieved file on every access.

Transparent Transactions

Marketplace transactions are recorded on-chain and can be tracked through the existing transaction system and verified on Sepolia Etherscan.
